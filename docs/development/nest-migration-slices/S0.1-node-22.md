# S0.1 — Node 22 no runtime

**Não instale Nest nesta fatia.**

## Objetivo

CI já usa Node `22.14.0`. Docker e docs ainda falam Node 18. Alinhar.

## Pode alterar

- `Dockerfile` (os dois `FROM node:18-alpine` → `FROM node:22-alpine`)
- `docs/development/setup.md` (pré-requisito `Node.js 18+` → `Node.js 22+`)
- `package.json`: adicionar `"engines": { "node": ">=22" }` no nível raiz (ao lado de `license`). Não mudar `scripts` nem dependências.

## Não alterar

Qualquer outro arquivo. Sem `npm install`. Sem Nest. Sem `tsconfig`.

## Gates

```bash
node -v   # ambiente local pode continuar 22; não falhar a fatia se o sandbox for outro
grep -n "node:22-alpine" Dockerfile
grep -n "Node.js 22+" docs/development/setup.md
```

`npm test` não é obrigatório aqui (nada de runtime da app mudou além da tag Docker). Se rodar e passar, melhor.

## Pronto quando

- Dockerfile builder e production usam `node:22-alpine`
- setup.md pede Node 22+
- `engines.node` é `>=22`

## Parar

Marque S0.1 em `PROGRESS.md`. Não abra S0.2.
